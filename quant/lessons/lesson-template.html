Lesson 1 · Number Properties

Number Systems

Understand the main categories of real numbers and how they relate.

01Lesson

Learning objectives

  • Identify common number sets.
  • Understand how number sets are nested.
  • Classify values efficiently in GRE questions.

1. Concept

Numbers can be classified into sets. A number may belong to more than one set. For GRE Quant, recognizing these categories helps you reason about whether a statement must be true.

Common number sets

  • Natural numbers: 1, 2, 3, … (some definitions include zero, so check context).
  • Whole numbers: 0, 1, 2, 3, …
  • Integers: …, −3, −2, −1, 0, 1, 2, 3, …
  • Rational numbers: numbers expressible as a ratio of integers, with nonzero denominator.
  • Irrational numbers: real numbers that cannot be expressed as a ratio of integers, such as √2 and π.
  • Real numbers: all rational and irrational numbers on the number line.
Natural ⊂ Whole ⊂ Integers ⊂ Rational ⊂ Real
A terminating or repeating decimal is rational. A nonterminating, nonrepeating decimal is irrational.

2. Worked example

Question: Which of the following is irrational?

A. 0.25   B. √9   C. 0.333…   D. √5

Correct answer: D. √5 is irrational. 0.25 = 1/4, √9 = 3, and 0.333… = 1/3, so the other choices are rational.
