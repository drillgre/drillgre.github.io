New lesson

Write lesson content directly in HTML. Use $...$ for inline equations and $$...$$ for block equations. In HTML mode, write inline LaTeX as $x^2 + y^2 = z^2$ and display equations as $$x^2 + y^2 = z^2$$. Standard HTML elements such as headings, paragraphs, lists, tables, links, and images are supported.

Shared Data Analysis stimulus

Create one shared chart, table, graph, or data context, then link exactly three Data Analysis questions to it. The mock test presents the stimulus once and keeps the three questions together.

After saving, select this group for each of its three questions. For mock eligibility, the three published questions must be Level 2, 3, and 4 for Section 1; Level 1, 2, and 3 for the easier Section 2 route; or Level 3, 4, and 5 for the harder Section 2 route.

Question explanation

Provide a written solution, a YouTube video explanation, or both.

Paste the normal YouTube video URL. The video will be embedded directly on the learner page.

Import questions

Upload an Excel workbook, CSV file, or JSON array. Review validation before importing.

Use the canonical category and subtopic IDs shown in the example CSV. For multiple-choice questions, use option_a to option_f and put the correct option label(s) in correct_answer. For Quantitative Comparison, use quantity_a and quantity_b. For Numeric Entry, use numeric_answer and optional numeric_tolerance. Leave unused cells blank.

Import a complete course package

One JSON file can create new lessons and attach their practice questions to the Question Bank.

Existing lessons are matched by slug and their content is never overwritten. New lessons and questions are imported as drafts. Duplicate questions are skipped. Review the preview before importing.

Import vocabulary from CSV

Upload a CSV or Excel workbook, review validation, then import the valid new words.

Required columns: day, word, and at least one meaning field. Optional columns: sn, category, synonyms, example1 to example3, and is_published. Existing words are skipped rather than replaced.
